## 📘 Overview

This project presents an **LSTM-based NLP model for textual plagiarism detection** by analyzing the **semantic similarity between document pairs**. The model learns linguistic representations from preprocessed textual data to identify similar and potentially plagiarized content.

The project was developed under **Prof. Nutan Kumar Tomar, Department of Mathematics, IIT Patna**.

## 🚀 Features

- Detection of textual plagiarism using **LSTM-based deep learning**
- Analysis of **semantic similarity between document pairs**
- **Text tokenization** for converting documents into numerical sequences
- **Sequence padding** for standardized model input
- **Text normalization and preprocessing** for deep learning
- Training and evaluation of the LSTM model for identifying similar content

## 🧩 Workflow

1. **Data Preprocessing:** Clean and normalize textual data to prepare documents for model training.
2. **Tokenization:** Convert textual documents into numerical token sequences.
3. **Sequence Padding:** Standardize sequence lengths for consistent LSTM model input.
4. **Model Training:** Train the LSTM model to learn meaningful linguistic representations.
5. **Similarity Analysis:** Analyze learned representations to identify semantic similarity between document pairs.
6. **Evaluation:** Evaluate the model's ability to identify similar and potentially plagiarized content.
